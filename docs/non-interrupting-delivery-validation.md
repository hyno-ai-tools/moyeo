# 중단 없는 추가 전달 검증

검증일: 2026-11-18

| 대상 | 실제 확인 결과 | 수정 |
| --- | --- | --- |
| Codex | app-server turn/steer 수신 및 최종 답변의 추가 지시 마커 확인 | 연결 준비 전 요청의 서버 대기열 접수 |
| Claude | 초기에는 첫 result에서 연결 종료 및 추가 입력 미처리. 수정 후 동일 연결에서 추가 입력 수신 및 마커 확인 | 첫 result 뒤 미처리 입력이 있으면 연결 유지 |
| AGY | 최초 prompt 전송 직후 추가하면 빈 결과 재현. 작업 이벤트 이후 추가 시 마커 확인. 수정된 onReady 경로에서도 재확인 | 실제 작업 이벤트 이후 준비 상태 노출 |

세 CLI의 구현 차이 유지: Codex 진행 턴 steering, Claude 동일 연결의 추가 user 메시지 처리, AGY ACP 추가 prompt. 모든 제공자에서 단일 답변 또는 동일한 네이티브 턴으로의 병합을 보장하는 의미 아님.

## 서버 처리

- 클릭 시 접수 후 입력창 해제, 방별 도착 순서 처리
- 준비 중이면 대기, 지원하는 진행 작업이면 추가 전달
- 종료되었거나 실시간 입력 미지원 전송 경로이면 기존 후속 작업 대기열 사용
- 동일 요청 ID 중복 전송 방지
- 수신 여부 불확실 시 자동 재전송 금지 및 내용 보존 알림
- 중단·방 세대 변경 시 미전달 항목 취소

## 검증 범위

- 실제 구독 CLI 호출: 임시 작업공간, 파일 작업 없는 마커 반영 요청
- Codex 비저장 테스트 세션 및 Claude no-session-persistence 사용
- AGY 별도 테스트 세션 사용, 기존 대화방 미변경
- 세 모델 모의 서버 통합: 준비 전 접수, 중복 요청, 실제 전달, 프로세스 재사용
- 순차 전달·취소·기존 후속 작업 순서 회귀 테스트
- 브라우저 화면 클릭 테스트 미실시
