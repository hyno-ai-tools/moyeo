# 다음 메시지 추천

- 앱 설정의 **다음 메시지 추천**에서 사용 여부 선택. 기본값 꺼짐. 현재 브라우저에 저장.
- 답변 종료 후 해당 방의 기본(주도) CLI와 선택 모델로 최근 사용자·모델 대화 최대 6개를 전달. 각 메시지는 최대 1,800자로 제한.
- 빈 입력창에 회색 추천 문장 표시. **Tab** 또는 **제안 넣기**로 입력, **Enter**로 전송. 직접 입력·Esc·방 전환 시 해제.
- 본 대화의 세션을 재사용하지 않는 별도 호출. 추가 구독 사용량 발생. 여러 탭의 동일 요청은 서버 메모리 캐시로 중복 방지.
- 추천 호출 제한 시간 45초. 실패하거나 유용한 추천이 없으면 표시 생략. 기존 채팅은 계속 사용 가능.
- Codex는 임시 홈과 ephemeral 세션, Claude는 세션 비저장 모드 사용. AGY는 새 세션의 plan/sandbox 모드 사용하므로 CLI 자체에 보조 호출 기록이 남을 수 있음. MoYEO 방 대화에는 추천 기록을 추가하지 않음.
- 추천은 사용자의 승인이나 명령이 아님. 전송 전 확인·편집 가능.
